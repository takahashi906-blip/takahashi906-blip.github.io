# 業務自動化ポートフォリオ

GAS、Python、CSV・Excelを使った業務自動化の制作事例をまとめた公開用サイトです。

- `dist/index.html`: 公開ページ
- `CASE_STUDY.md`: 各制作事例の説明
- `CROWDWORKS.md`: クラウドワークス掲載文・提案文
- `VIDEO_SCRIPT.md`: PriceScope操作動画の台本

## 掲載事例

1. Googleスプレッドシート食数管理システム
2. Python Webデータ集計・レポート更新ツール
3. CSVからGoogle Sheetsへの自動取込
4. Excel帳票・配置図の自動作成
5. 関連実績としてPriceScope

公開ページはすべてサンプルデータで構成し、氏名、拠点の非公開情報、認証情報、アクセスキー、サービスアカウント鍵を含みません。

## 公開方針

- 実運用データと公開ページを分離する
- スクレイピング・データ取得は、利用許可と規約を確認できる方法だけを案内する
- 導入効果を掲載する場合は、実績値と試算値を区別する
- ソースコードは原則非公開とし、必要に応じて画面共有で動作を説明する
